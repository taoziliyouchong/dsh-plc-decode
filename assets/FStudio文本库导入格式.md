# FStudio 文本库导入格式（繁易 Flexem）

做多语言时，给 FStudio 文本库**导入**用的表，格式必须与软件**导出**的 TextLib 表逐字符一致，
否则软件报"文件格式不正确"。踩过一次坑，记在这里。

## 表结构

单表，表名随意（软件导出叫 `TextLib`）。表头**必须**是这 5 列（有俄语就 6 列）：

| 列 | 内容 | 说明 |
|---|---|---|
| 1 | `Guid` | 条目唯一标识，UUID 形如 `20c4864f-29ba-46c4-b9a5-beef83fbcad2`。新条目自己生成 UUID4 |
| 2 | `Name` | 条目名，建议 ≤50 字，勿换行（软件里列表显示用） |
| 3 | `Status` | 状态号，**数字**：默认值节点写 `0`，多状态依次 1、2… |
| 4 | `1-Chinese (Simplified, PRC)-2052` | 简体中文（LCID 2052） |
| 5 | `2-English (United States)-1033` | 英文（LCID 1033） |
| 6 | `3-Russian (Russia)-1049` | 俄语（LCID 1049），不用就别加这列 |

- 列名里空格、括号、连字符都不能改；`Guid`/`Name`/`Status` 首字母大写。
- 简体中文那列的列名尤其容易写错成"中文"——**写"中文"就导不进去**。
- 一个条目若有多状态，导出的表是"Guid 只在首行、后续行 Guid 留空"，同 `Name`、`Status` 递增。
  自己造导入表时**每行都给 Guid** 更稳。

## 生成脚本

`出文本库导入表.py`：把中文英文对照表转成上面的格式。

```
python 出文本库导入表.py <对照表.xlsx> [输出.xlsx]
```

- 输入表要求：有一列列名含「中文」、一列含「英文」或 `English`。
- 输出：**一份**可导入的 `.xlsx`（默认只出一份，别一次给多个表）。需要 `.xls` 时加参数：`--xls`。
- 每个条目 Guid 自动生成、Status=0、Name 取中文前 50 字、英文为空的行标黄底提示。

## 导入前自查（3 条）

1. 表头逐字符对：`Guid` / `Name` / `Status` / `1-Chinese (Simplified, PRC)-2052` / `2-English (United States)-1033`。
2. Guid 无重复、非空；Status 是数字不是文本。
3. 库里已有的条目先核一遍，别把同名条目导成两条。

## 相关

- 文本库在工程里的位置：`Global\TextLibConfigInfo.cfg`；语言表：`HMI\System\LanguageConfigInfo.cfg`。
- 画面元件想随语种变，还得逐个元件勾「使用文本库」指到条目（FStudio 使用手册 4.13.8 标签编辑器，p.570-571）。
