# ladder-workflow —— 文字梯形图的排版规范与自动成图

要交"文字梯形图"（讲解、改动方案、对照说明）时用本技能。样式已固化成代码，**不要手敲空格、不要自创排法**：
手敲必然对不齐，自创必然返工。两条路都走工具。

## 一、两条路

| 输入是什么 | 用哪个 | 命令 |
|---|---|---|
| 指令表／语句表（STL，含 `LD/A/O/=/TON/…`） | 工具 `ladder-from-stl` | `/ladder-stl <语句表.txt> [输出.txt]` |
| 只有元件与引脚的信息（截图、解码结果、口述） | 工具 `ladder-render` | `/ladder <spec.json> [输出.txt]` |
| 台达 DVP 工程文件 | 工具 `ladder-dvp` | `/ladder-dvp <工程.dvp> [起段] [止段]` |
| 西门子 S7-200 SMART 工程文件 | 工具 `ladder-auto` | `/ladder-auto <工程.smart> [块名] [网络]` |

**能拿到工程文件或 STL 就走自动那条**：串并联写在文件里，成图是确定的，不用猜；只有拿不到才走 spec 手写。

## 二、STL 自动成图

认得的写法（S7-200 / S7-200 SMART）：

- 触点 `LD/LDN`、`A/AN`、`O/ON`、`NOT`
- 逻辑堆栈 `ALD`、`OLD`、`LPS`、`LRD`、`LPP`
- 边沿 `EU` → `┤P├`，`ED` → `┤N├`
- 比较触点两种写法都认：`LDD=`／`AD<>`／`OW>`，以及 `==I`／`<D`／`>=R`
- 输出 `=`（线圈）、`S`/`R`（可带个数）、`CALL`（子程序与库块）
- 指令盒 `MOV_`、`TON/TOF`、`CTU/CTD`、`INC/DEC`、算术、移位…

行为约定：

- 每个网络出一段梯体 + 一句机械讲解（"当……时，……"）；`summary=false` 可关掉讲解。
- **认不出的写法不猜**：按盒原样画，讲解里标"未识别写法"。看完必须人工核一遍再交。
- 定时器／计数器的编号进盒名（`TON T57`），不当引脚；`PT`/`PV` 才是引脚。
- 网络分隔：`Network N`／`网络 N`；`//` 开头的行当网络注释保留。

## 三、只有元件信息时（spec 渲染）

```json
{
  "title": "可选标题",
  "legend": true,
  "networks": [
    {
      "name": "网络 7",
      "note": "盒名（可选补充）",
      "rows": [
        { "left": "Alw~:SM0.0 ──┤ ├", "pinL": "EN" },
        { "left": "C1 ─┤==I +0├──┤P├", "pinL": "First" },
        { "left": "40100", "pinL": "Addr" },
        { "left": "2", "pinL": "Count", "pinR": "Done", "out": "M0.1" }
      ],
      "comments": ["EN 常通——盒每扫描都被调用；", "First 只在 C1==0 的上升沿给一拍。"]
    }
  ]
}
```

| 字段 | 写什么 |
|---|---|
| `rows[].left` | 方框左侧的导线与元件画法（触点、比较、常数、地址）。只写 ASCII 与制表符，**不混中文** |
| `rows[].pinL` / `pinR` | 方框左／右引脚名，用软件里的英文名（EN、First、Addr、DataPtr、Done、Error、ENO…） |
| `rows[].out` | 方框右侧导线去向（`VW198`、`M0.1`）；**有 out 必须给 pinR** |
| `rows[]` 一行 | 一根导线；按软件的引脚顺序排 |
| `comments[]` | 网络下方的中文说明 |
| `plain: true` | 没有指令盒的网络（直接以线圈收尾）：只画导线，不画方框 |

## 四、画法约定（照软件观感）

- 常开触点 `┤ ├`　常闭触点 `┤/├`　上升沿 `┤P├`　下降沿 `┤N├`
- 比较触点带参数写：`┤==I +0├`、`┤<I 最高速度├`
- 数值／地址写在导线上：`40100 ────┤ Addr`
- 线圈 `──( Q1.7 )`、置位复位 `──( S M25.6, 2 )`
- 盒名放网络标题（`name` + `note`）或盒内；不塞进引脚行
- 多支路（母线拉出多条并联）用自动成图的 `ladder-dvp`／`ladder-auto`；手写 spec 只适合单支路

## 五、交付前自检

1. 渲染器自带结构自检（中文混进梯体、有 out 没 pinR、空网络都会点出来）——**不过先改，别交**。
2. 对着源头逐行核：每根导线上的值、每个引脚名都能在程序里指出来；**不确定的接线不画成确定的样子**，宁可空着并在 comments 写"待核"。
3. 自动成图后重点核三处：比较触点、边沿、`LPS/LRD/LPP` 拆出来的并列支路——这三处最容易看错。
4. 图上看不懂的元件（画成 `?`／`〔?…〕`）不要当成已知交出去：写明是哪一段、什么字节，交给用户对账。
